Prompt: 

Criar um aplicativo de sommelieria de cervejas, vinhos, drinks e destilados. Servirá para que os usuários possa catalogar as bebidas degustadas, com foto e dados de cada uma.

A. Definições Gerais
1. Nome do projeto e do sistema: Toastrack
2. Slogam: Seu aplicativo completo de Sommelieria
3. Pasta de Fontes: C:\Claude\Toastrack
4. Repositório GitHub: https://github.com/cribeirox7i/toastrack
5. Projeto Supabase: https://supabase.com/dashboard/project/ngcsfrhxivipkabsised

B. Definições técnicas:
1. Linguagem de front: TypeScript, React com o framework Next.js e Tailwind CSS
2. Linguagem de back-end: Rust
2. Hospedagem (front e back): GitHub Pages
3. Banco de dados: Supabase
4. Armazenamento de imagens de perfil e imagens gerais da aplicação: Supabase Storage

C. Segurança e Acesso
1. App deve ter tela de login com e-mail e senha. Opção de ocultar e exibir senha digitada.
2. Senha deve ter complexidade mínima (8 caracteres, letra maiúscula, letra minúscula, número e caracter especial)
3. Deve ter duplo fator de autenticação, com token por e-mail;
4. Deve ter opção de cadastro (Criar Conta), para usuários não cadastrados;
5. Deve ter opção de Esqueci Minha Senha, com envio de e-mail para o e-mail cadastrado.
6. Usuário terá um campo de status (ativo / inativo).
7. Todos os acessos e modificações devem ser logados em tabela de log.
8. Deve manter a seção logada por 15 dias sem acesso. Após isso, logout.

D. Definições de usabilidade
1. Criar um dashboard na tela inicial contendo estatísticas sobre quantidade geral de cervejas, vinhos, drinks e destilados, e quantidade por categoria;
2. Criar um pequeno carrossel de 3 páginas com Destaque do Dia, onde vai aparecer uma cerveja, um vinho e um drink ou destilado cadastrados, randomicamente.
3. Criar menus principais (barra inferior): Home, Cervejas, Vinhos, Drinks e Destilados.
4. Criar telas de login e acesso conforme descrito na seção C. Segurança e Acesso
5. As telas de listagem de Cervejas, Vinhos e Drinks devem ter 3 opções de vizualização (deck, tabela e galeria).
6. Deve ter opções de inclusão de itens, exclusão, edição, e duplicação de registro.
7. Sistema deve ser multi-idioma, com seletor (espanhol, inglês e português)
8. Deve haver gestão de perfil. Dentro do perfil, opção de troca senha, seleção de idiomas e seleção de perfil de cores (paleta verde, paleta azul, paleta vermelha, paleta laranja, paleta amarela, dark-mode, light-mode).
9. Na gestão de perfil, opção de nome amigável de usuário;
10. Na gestão de perfil, opção de foto de perfil;
11. Na gestão de perfil, mostrar e-mail associado à conta.
